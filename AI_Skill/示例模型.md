        # 基础缓存替换算法（LRU / LFU / FIFO / MRU / Random）

        > 覆盖五种经典替换算法及其命中率分析工具，是全部缓存算法的公共基础层。

        ## 1. 概述与适用场景

        - **覆盖**：LRU、LFU、FIFO、MRU、Random 的机制、复杂度、典型命中率行为、Che 近似分析；一致性视角下的公共定义。
        - **适用**：为新系统设计选择基线算法；评审文档中算法结论；用 trace 或合成负载快速估算命中率上界/下界。
        - **不适用**：需要扫描抵抗或准入控制的场景（→ cache-algorithms-advanced）；学习型策略（→ learning-driven-cache）；分布式放置（→ distributed-cache-algorithms）。

        ## 2. 核心要点

        1. LRU 在 IRM（独立引用模型）下的命中率有 Che et al. 闭式近似：`hit ≈ Σ_{i=1}^{c} p_i`，其中 `p_i` 为按引用概率排序的第 i 个对象命中概率，可用迭代不动点求解（推导自 Che, Wang, Tung 2003）。
        2. LRU 实现为哈希表 + 双向链表：O(1) 命中/插入/驱逐；LFU 需维护频率计数，精确实现常用平衡树或哈希桶链表，Redis 采用近似 LFU（对数计数 + 随时间衰减，MFU/LFU 两条链，见 05.05.02）。
        3. FIFO 无命中提升（hit 不改变顺序），扫描（scan）负载下抗污染优于 LRU——这是 S3-FIFO/SIEVE 重新兴起的动机（SOSP'23/NSDI'24）。
        4. MRU 在"顺序扫描必然不重用"负载下是最优策略，但典型业务负载下最差，仅作理论对照。
        5. Random 命中率期望 ≈ 命中频率为 k/N 的均匀抽样，工程上常作为无锁实现的基线（如 memcached 早期失效策略讨论）。
        6. 复杂度上界：所有确定性算法单操作 O(log n) 可实现；常数因子差异来自指针追逐与缓存局部性（见 02.02 CPU 缓存）。
        7. 一致性风险：LRU/FIFO 驱逐窗口内并发读写需加锁或无锁化；Redis 在 evict 路径采用近似采样驱逐降低锁持有时间。

        ## 3. 权威速查

        | 算法 | 数据结构 | 命中 | 插入 | 驱逐 | 扫描抵抗 | IRM 最优 |
        | ---- | -------- | ---- | ---- | ---- | -------- | -------- |
        | LRU | Hash+双向链表 | O(1) | O(1) | O(1) | 差 | 是（近似） |
        | LFU | Hash+频率桶 | O(1) 近似 | O(1) | O(1) | 好（热数据常驻） | 频率静态时最优 |
        | FIFO | Hash+队列 | O(1) | O(1) | O(1) | 中 | 否 |
        | MRU | 同 LRU | O(1) | O(1) | O(1) | 最差 | 否 |
        | Random | Hash+数组 | O(1) | O(1) | O(1) | 中 | 否 |

        - LRU 近似命中率（Che et al. 2003）：`p_i` 满足 `p_i = 1 - exp(-Σ_{j} ...) ` 迭代至收敛；项目公式对照表 B 级，推导自 [Che et al., IMC 2003]。

        ## 5. 常见任务工作流

        ### 任务 A：为新业务选基线算法

        1. 确认负载特征：重用距离分布（短尾→LRU；重尾+热点→LFU；含扫描→FIFO/S3-FIFO）。
        2. 用 `python scripts/benchmark/trace_benchmark.py` 跑合成 Zipf 对比 LRU/LFU（约 10 秒）。
        3. 查 [01.05.04](../../docs/01-理论基础/01.05-算法对比与决策/01.05.04-算法性能基准测试.md) §6 公开 trace 接入指引，用 MSR/Twitter trace 复核。
        4. 决策输出：基线 + 预期命中率 + 风险（写入设计文档）。

        ### 任务 B：核对文档中的算法结论

        1. 打开对应 01.01.xx 文档；2. 对照 §2 要点逐条检查；3. 公式查 [公式-文献对照表](../../docs/00-项目总览/公式-文献对照表.md) 是否登记；4. 发现出入 → 登记 STATUS.md 变更记录。

        ## 6. 国际前沿对齐（截至 2026-11）

        - S3-FIFO（SOSP'23）与 SIEVE（NSDI'24）证明 FIFO 系在真实 trace 上可超过 LRU，推动"FIFO 复兴"；libCacheSim 2026-11 的 PrefixSim 已将驱逐策略对比扩展到 LLM KV-block 前缀缓存（[cachemon/libCacheSim](https://github.com/1a1a11a/libCacheSim)）。
        - 分析工具：cheapr 等闭式近似仍是对数成本估算的主流（CMU 缓存研究组，[cachemon](https://cachemon.github.io/)）。
        - 教学结论无变化：LRU/LFU 仍是入门与理论分析的基线。
