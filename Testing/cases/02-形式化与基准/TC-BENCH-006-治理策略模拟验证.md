## 预期结果（2026-11-17 基线）

| 场景 | 防护 | 回源总量 | 回源峰值（10ms 窗） |
| ---- | ---- | -------- | ------------------ |
| 穿透 | 布隆+空值 | -69% | 持平（顺序负载峰值为 1） |
| 击穿 | 互斥重建 | -100% | **-99%（200 并发→1）** |
| 雪崩 | TTL 抖动 | 持平 | **持平（场景为顺序请求，峰值恒为 1）** |

**判读**：顺序请求负载下穿透/击穿的总量与峰值收益显著；雪崩的"峰值摊平"收益需并发请求负载才可见（脚本为单机模拟，结论用于机制演示而非容量数据）。击穿的 -99% 峰值收益是本实验核心证据（04.44.03 互斥重建的量化背书）。

## 失败纠正与修正指引

1. 收益为负：检查防护实现是否真生效（布隆预置、互斥锁逻辑）。
2. 结果大幅漂移（>20pp）：随机种子/参数被改；确需变更时更新本表基线。
3. 修正：本实验为机制演示（单进程模拟），容量级数据以 redis-benchmark/memtier + 故障注入（TC-CLUS-007）为准。
