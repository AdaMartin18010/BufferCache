# 自我测试验证更新修正机制

> 本文件定义 BufferCache 项目的**持续自我验证机制**：验证（verify）→ 诊断（diagnose）→ 纠正（correct）→ 修正（fix）→ 回归（regress）→ 登记（record）闭环。工具落点是 [self_verify.py](self_verify.py)；用例落点是 [cases/](cases/)。

## 1. 闭环六环节

| 环节 | 定义 | 执行者 |
| ---- | ---- | ------ |
| 验证 Verify | 按用例执行检查，产出结构化结果 | self_verify.py（自动）/ 人工演练 |
| 诊断 Diagnose | 失败项定位到文件、行、根因类别 | self_verify.py 输出 + 用例修正指引 |
| 纠正 Correct | 修复本次问题（如改链接、补平台守卫） | agent / 人 |
| 修正 Fix | 消除根因防复发（改模板、加 CI 守卫、更新规范） | agent 提案 + 人审 |
| 回归 Regress | 复跑相关子集确认转绿且无次生问题 | self_verify.py |
| 登记 Record | 影响范围大的变更写入 STATUS.md 变更记录 | agent / 人 |

## 2. 三层执行体系

```text
┌─────────────────────────────────────────────────────┐
│ L3 人审层：季度前沿评审 / 文档内容抽检 / 演练裁决      │
├─────────────────────────────────────────────────────┤
│ L2 agent 层：AI_Skill 技能驱动（16 个技能 §7 验证命令）│
│              变更评审、文档核对、前沿对齐              │
├─────────────────────────────────────────────────────┤
│ L1 自动层：self_verify.py（提交前/CI 全量）            │
│   docs | links | formal | bench | ops | structure    │
└─────────────────────────────────────────────────────┘
```

- **L1 是门禁**：任何 docs/、AI_Skill/、Testing/、scripts/ 变更提交前必须 `python Testing/self_verify.py all` 转绿（CI 中以 `--ci` 强制非零退出）。
- **L2 是放大器**：agent 按 [AI_Skill](../AI_Skill/README.md) 技能 §5 工作流执行评审/核对类任务，把 L1 判不了的内容（结论正确性、前沿时效）纳入验证。
- **L3 是裁决者**：争议与高风险变更（版本事实、公式出处、结构性调整）由人裁定。

## 3. 频率矩阵

| 触发 | 动作 | 覆盖 |
| ---- | ---- | ---- |
| 每次提交（本地/CI） | `self_verify.py all --ci` | L1 全量 |
| 新增/修订 AI_Skill | `self_verify.py links --path AI_Skill` + 技能 §7 | L1+L2 |
| 每周（维护窗口） | `self_verify.py bench ops` + 集群用例抽检 | L1+部分 L2 |
| 每月 | 故障演练轮换（TC-CLUS-003/004 之一） | L3 |
| 每季度 | 前沿评审：version_monitor 全量 + 16 技能 §6 逐条核验 + 权威来源索引更新 | L2+L3 |
| 每年 | 机制本身评审（本文件与 AGENTS.md §5 的适配性） | L3 |

## 4. 失败升级规则

1. L1 失败 → 按用例"失败纠正与修正指引"处理；同一用例连续 3 次失败 → 触发 L2 根因分析（判断是内容问题还是检测器缺陷）。
2. 检测器缺陷（误报/漏报）→ 修 self_verify.py 或 code_test_framework.py，并补回归用例。
3. 涉及权威事实冲突（文档 vs 技能 vs 外部来源）→ L3 仲裁，以 [AI_Skill/权威来源索引.md](../AI_Skill/权威来源索引.md) A 级来源为准。

## 5. 产物与纪律

- 报告输出到 `Testing/output/`（已 .gitignore），不落库；需要留档的摘要写入 STATUS.md 变更记录或 reports/。
- 不新建"测试完成报告"类元文档（[AGENTS.md](../AGENTS.md) §4.2.1）。
- self_verify.py 自身变更必须经 TC-INT-001 全量回归 + 人工 review。
