# Redis版本更新计划

## 📋 版本更新概览

**检测日期**：2026-01-06
**当前文档版本**：Redis 7.0（部分文档使用7.2）
**最新发布版本**：Redis 8.4.0（8.0 GA 于 2025-05，8.4 GA 于 2025-11）
**更新优先级**：P0（高优先级）
**执行状态（2026-01 更新）**：**策略调整——不做全库机械替换**

## 🎯 更新策略（2026-01 修订）

经评估，85+ 文档的机械版本号替换风险大于收益（示例中的版本号多为上下文标注，机制分析对次版本不敏感）。改为以下策略：

1. **集中式版本档案**：版本演进、许可变迁、生态分裂的权威内容已归入新文档 [03.05 Redis版本演进与开源生态](../03-Redis组件/03.05-Redis生态与版本演进/README.md)（含 7.4 许可变更、8.0 AGPLv3、8.2/8.4、Valkey/Redict/KeyDB/Dragonfly/Garnet 对比与选型）
2. **存量文档口径**：03.x 各文档的机制分析（数据结构/持久化/复制/内存管理）基于 6.x/7.x，对 7.2+ 依然成立；版本敏感差异（listpack 替代 ziplist、模块内置化、Graph 停更）已在 03.05 第 7 节统一说明
3. **增量更新**：后续新增/修订文档以 8.x 行为为基准；发现具体文档中的版本性错误时单独修复

**关键版本事实（已核实）**：

| 版本 | 时间 | 要点 |
| ---- | ---- | ---- |
| 7.4 | 2024-03 | 许可变更（BSD→RSALv2+SSPLv1），触发 Valkey/Redict 分叉 |
| 8.0 | 2025-05 | 新增 AGPLv3（三重许可）；Search/JSON/TimeSeries/Bloom 内置；Vector Set（beta） |
| 8.2 | 2025 | 向量集增强、性能优化 |
| 8.4 | 2025-11 | 混合全文+向量检索、吞吐提升 30%+、原子操作改进（含 Vector Set 安全修复） |
