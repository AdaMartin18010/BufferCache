## 漂移处理流程

```text
季度评审发现漂移（如 A1 出现 8.14）
  → 以权威来源索引 A/B 级出处仲裁
  → 更新所在文档正文（~~旧值~~ 新值标注或改写）
  → 更新 AI_Skill 对应技能 §6
  → 更新本表（最后核验日期重置，必要时改断言表述）
  → 大漂移登记 STATUS.md 变更记录
```
