# 全局一致性规范（思维表征层的唯一权威规则）

> 本规范是 BufferCache 项目**思维表达层**（概念/决策/矩阵/推理/导图）的唯一权威规则：定义模板、权威源归属、一致性校验方法。目标：273 篇文档、20 技能、40+ 决策流程在概念理解、判定结论、推理链三个层面保持全局一致，且递归判断（决策树之间的跳转）始终可追踪到叶级判定依据。

## 1. 四层一致性模型

```text
概念层 —— 一个概念一个权威定义（概念定义汇总 v2），其余位置引用不复制
决策层 —— 一个决策点一个权威判定（决策图网 v2），文档内的决策树是投影
矩阵层 —— 一个对比维度一个权威口径（多维概念矩阵对比 v2），新表先登记后引用
推理层 —— 一条推理链必须落到 A/B 级出处（公式-文献对照表 / 权威来源索引）
```

**规则 1（权威源唯一）**：任何概念/判定/对比的"定义性表述"只出现在其权威源；其他文档只允许引用（链接）或原样摘录并标注出处。发现第二处定义性表述 → 迁移到权威源并回链。

**规则 2（改动单点广播）**：权威源变更后，引用方由第五道门禁（一致性巡检）发现漂移，禁止手动逐处同步。

**规则 3（口径分级）**：定量表述必须带 A/B/C 级出处（同公式对照表分级）；C 级经验值必须在权威源声明假设。

## 2. 概念五维模板（Q1 执行标准）

每个核心概念在 [概念定义汇总](概念定义汇总.md) 中按五维登记：

```text
【定义】一句话精确定义（含数学表述时给出符号）
【属性】≥3 条可判定属性（什么一定成立）
【关系】与 ≥2 个相关概念的关系（继承/对立/组合，链接到概念关系图谱）
【示例】一个具体实例（工程场景）
【反例】一个"看似属于但不属于"的边界反例 + 排除理由
```

分级管理：P0 概念（跨 ≥3 主题被引用）必须五维齐全；P1 概念可暂缺"反例"，随季度评审补全（在条目标注 ⚠）。

## 3. 决策三层索引与递归决策规则（Q2 执行标准）

```text
L1 主决策树（决策图网 v2 总入口）：跨领域的第一问（如"数据可重建？"）
   ↓ 节点跳转
L2 领域子树（登记在决策图网）：单一领域的判定流程（如"持久化决策"）
   ↓ 节点跳转
L3 判定叶（= 文档章节）：具体判定条件与参数，叶子带文档锚点
```

**递归有效性四要求**：

1. 每个 L1/L2 节点的跳转目标必须存在（链接可解析，第五道门禁校验）；
2. 每个 L3 叶子的判定条件与文档正文**逐字一致**（巡检断言：叶子文本 ⊆ 文档文本）；
3. 决策结论冲突检测：同一问题（以"判定指纹"标识，如 `纯缓存+可回源→驱逐策略`）在全部决策树中结论唯一（巡检断言）；
4. 决策路径终止性：任一 L1 起点沿跳转必达 L3 叶子（无环、无悬空——靠链接检查+人工评审保证）。

**判定指纹格式**：`<输入条件摘要>→<结论>`，例：`纯缓存+可重建→无持久化/RDB 兜底`。

## 4. 矩阵登记规则（Q3 执行标准）

- 新对比表必须先入 [多维概念矩阵对比](多维概念矩阵对比.md) 登记（维度清单+取值+口径出处），文档中的表格是投影；
- 矩阵条目必须含"反例场景"列（什么情况下该对比结论不成立）——保证矩阵不被误用为绝对结论。

## 5. 推理链引用规范

- 文档中的推理链（"因为 X 所以 Y"结构）的 X 必须可溯源：数学结论→公式对照表；事实结论→权威来源索引；项目经验→事实断言清单 C 级。
- 推理链跨文档时，终点文档必须反向链接推理起点（双链）。

## 6. 一致性校验（第五道门禁）

`scripts/assertion_check.py` 新增两类检查（Q5b 落地）：

| 检查 | 内容 |
| ---- | ---- |
| 概念三方对 | 概念定义汇总中的 P0 概念关键词 ↔ 技能 §2 ↔ 正文，三方表述一致性抽查 |
| 决策冲突检测 | 判定指纹清单（决策图网维护）↔ 各文档决策树结论，grep 双端比对 |

漂移处置：以权威源为准修正投影方；权威源本身的错误按"权威来源索引仲裁→修正→登记变更记录"流程。

## 7. 与其他机制的关系

- 第四道门禁（技能-正文巡检）管"技能与正文的事实一致"；本规范管"思维表征之间的一致"——两者互补，assertion_check 统一执行。
- 事实断言清单管"版本化事实"；本规范管"结构性知识"（概念/判定/对比）——前者是后者的数据源之一。
- 季度评审职责扩展：概念反例补全（P1→P0）、决策树新增登记、矩阵口径复核。
