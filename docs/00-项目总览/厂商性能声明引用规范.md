# 厂商性能声明引用规范

> 项目大量引用厂商性能数据（Valkey 2.1M RPS、Dragonfly 3.82M、vLLM 3.8×、Mooncake 100× 等）。本规范定义**引用纪律**，防止厂商基准成为"无出处公式"的新变种。与 [全局一致性规范](全局一致性规范.md) 互补：管"推理链出处"，本规范管"性能数字的引用条件"。

## 1. 分级规则

| 级别 | 条件 | 使用限制 |
| ---- | ---- | -------- |
| A（可对比引用） | 同行评审论文基准 + 可复现 artifact（Garnet VLDB'26） | 可作选型依据 |
| B（条件引用） | 官方基准 + **完整测试条件披露**（硬件/负载/pipeline） | 引用时必须附条件；可作方向判断 |
| C（声明引用） | 官方基准 + 条件不完整（Valkey 2.1M 官方博客——无硬件细节摘要） | 只作"厂商宣称"，正文必须出现"宣称"字样 |
| D（禁独立引用） | 厂商基准 + 对手产品对比（Dragonfly vs Redis 厂商跑分） | 只作背景，禁止作选型输入 |

## 2. 引用格式（强制）

```text
首次引用：数字 + 条件摘要 + 出处 + 级别标注
  例：2.1M RPS（512B 负载、9 I/O 线程、pipeline 10，官方基准，C 级宣称；
      第三方 Percona/AWS 方向一致）
对比引用：≥2 个独立来源（其中 ≥1 非厂商）
```

## 3. 审计义务

- 新增厂商数字时按本规范定级；历史引用由季度评审逐步回标（事实断言清单 C 类已含部分）。
- 项目自己的实测（redis-lab）不受本规范限制，但必须在 [事实断言清单](事实断言清单.md) 登记测试条件。
- 违反（C/D 级当结论用）由一致性巡检（assertion_check）抽查发现。
