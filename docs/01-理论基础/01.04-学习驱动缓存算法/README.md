## 1. 概述

### 1.1 定义与动机

**学习驱动缓存算法（Learned Cache Replacement）**利用机器学习模型（多臂老虎机、强化学习、监督学习、后悔最小化）替代或增强人工设计的启发式替换规则（LRU/LFU/ARC），根据观测到的访问历史自适应地做出驱逐决策。

**动机**：启发式算法基于固定的局部性假设（时间局部性→LRU、频率局部性→LFU），而真实工作负载是时变且异构的。学习型策略的假设是：访问模式中的可学习结构（程序行为、用户会话、内容流行度演化）可以被模型捕获，从而获得超越任何单一启发式的命中率。

**性能证据**（以 MPKI——每千指令缺失数——衡量，数值越低越好）：

| 算法 | 类型 | 相对 LRU 的 MPKI 降低 |
| ---- | ---- | ---------------------- |
| LRU | 启发式 | 基准 |
| Hawkeye | 监督学习（预测） | ~13.6% |
| LeCaR | 后悔最小化 | 小缓存场景显著 |
| CACHEUS | 强化学习 | 平均 4-11%（依赖负载） |
| 3L-Cache | 低开销学习 | 接近 Hawkeye 精度 |

### 1.2 分类学

```text
学习驱动缓存算法
├── 决策级学习（Policy-level）：学习器直接做驱逐决策
│   ├── 后悔最小化：LeCaR（专家加权）
│   ├── 强化学习：CACHEUS、LRB、3L-Cache
│   └── 监督学习：逐对象"是否会被重用"分类器（Hawkeye 的 predictor）
├── 预测级学习（Prediction-level）：学习器预测未来，启发式规则决策
│   └── Hawkeye（预测 cache-friendly 对象，OPT 近似规则执行驱逐）
└── 应用域
    ├── CPU/芯片缓存（Hawkeye、SHiP++）
    ├── 系统缓存（LeCaR、CACHEUS、LRB、3L-Cache）
    ├── 边缘/CDN 缓存
    └── LLM KV Cache 驱逐（RL 重排 token，见 01.04 第 9 节与 04.03.15）
```

## 2. 理论框架：在线学习与后悔值

### 2.1 缓存作为在线决策过程

缓存替换是在线决策问题：每一步必须在信息不完整（不知道未来访问）时做出驱逐选择。形式化为：

- **状态**：当前缓存内容 $S_t \subseteq \mathcal{I}$、访问历史、学习器内部参数（权重、模型）
- **动作**：驱逐哪个对象
- **奖励**：后续访问是否命中（延迟观测）

这与 [01.01 LRU 竞争比分析](../01.01-基础替换算法/01.01.01-LRU算法原理与实现.md) 中的在线算法框架一致，但增加了学习器根据历史更新策略的能力。

### 2.2 后悔值最小化

设有 $N$ 个"专家"（候选启发式策略，如 LRU、LFU），学习器维护权重 $w_t(i)$，第 $t$ 次驱逐时按归一化权重 $\tilde{w}_t(i) = w_t(i)/\sum_j w_t(j)$ 随机选择专家 $i$ 执行驱逐。

驱逐结果（是否很快再次命中被驱逐对象）产生各专家的后悔值 $r_t(i)$，按乘法权重更新：

$$w_{t+1}(i) = w_t(i) \cdot (1 - \eta)^{r_t(i)}$$

或指数加权（Hedge 算法形式）：

$$w_{t+1}(i) = w_t(i) \cdot e^{-\eta \, r_t(i)}$$

其中 $\eta$ 为学习率。**后悔值界**：经过 $T$ 次决策，累积后悔值 $R_T = \sum_t r_t(a_t) - \min_i \sum_t r_t(i)$ 以 $O(\sqrt{T \log N})$ 增长——即长期来看不显著差于最优固定专家。这是 LeCaR（第 4 节）的理论基础。

### 2.3 学习增强在线算法的竞争比

经典竞争比（competitive ratio）刻画最坏情况；学习增强（learning-augmented）分析引入两个参数：

- **一致性（consistency）**：预测完全正确时的竞争比，理想为 $1 + \epsilon$
- **鲁棒性（robustness）**：预测任意错误时的竞争比上界，理想不超过无预测时的常数倍

形式化（Lykouris & Vassilvitskii, 2018 的一般框架应用于缓存）：给定预测 $\hat{\sigma}$，算法竞争比为：

$$CR \leq \min\left\{ \alpha(\eta),\ \beta \cdot CR_{经典} \right\}$$

其中 $\eta$ 为预测误差。该框架为"学习型缓存"提供了严格理论工具：好的学习型算法应在预测准确时接近最优、预测失效时退回经典保证。**这是评估一切学习型缓存算法的理论标尺**。

## 3. Hawkeye：缓存访问预测的开山之作

Hawkeye（Jain & Lin, ISCA 2016）是芯片缓存（LLC）上首个高精度的学习型替换，思想被后续系统级学习缓存广泛继承：

1. **预测器**：离线训练监督模型（逻辑回归 / PC-based features），预测"当前访问的对象是否会被快速重用"（cache-friendly vs cache-averse）
2. **OPT 近似**：Belady 的最优离线算法（MIN）驱逐"下次使用最远"的对象；Hawkeye 用预测结果近似——预测为 cache-averse 的对象中"最久未被使用"者被优先驱逐
3. **收益**：相对 LRU 降低约 13.6% MPKI，接近理论可达上限的 79%

**关键洞察**：学习不直接替代决策规则，而是提供"未来是否重用"的信号，由经典规则消化。这一"预测-决策分离"设计大幅降低了学习器的决策风险。

## 4. LeCaR：后悔最小化的双专家缓存

### 4.1 算法设计

LeCaR（Learning Cache Replacement，Vietri et al., HotStorage 2018）将缓存驱逐建模为多臂老虎机问题：

- **两个专家**：LRU（时间局部性）与 LFU（频率局部性）
- **历史队列**：维护两个与缓存等长的驱逐历史 $H_{LRU}$、$H_{LFU}$，记录各专家驱逐的对象
- **驱逐决策**：按权重 $\tilde{w}(LRU)$、$\tilde{w}(LFU)$ 随机选择专家执行驱逐

### 4.2 权重更新规则

当被驱逐对象 $x$ 在后续访问中再次出现时（即驱逐错误），计算各专家的后悔值：若 $x \in H_i$（专家 $i$ 驱逐过 $x$），则 $r(i)$ 增加；然后乘法权重更新：

$$w(i) \leftarrow w(i) \cdot (1 - \eta)^{r(i)}$$

学习率 $\eta$ 取 $\Theta(1/\sqrt{T})$ 量级以保证后悔值界。

### 4.3 理论保证

- 对任意工作负载，累积后悔值 $R_T = O(\sqrt{T})$（双专家情形）
- 当负载偏向时间局部性时权重收敛至 LRU，偏向频率局部性时收敛至 LFU；混合负载下自适应组合
- **局限**：仅两个专家表达能力有限；随机化引入决策抖动；历史队列的开销为 $O(k)$（$k$ 为缓存容量）

## 5. CACHEUS：多策略强化学习缓存

CACHEUS（Rodriguez et al., FAST 2021）将策略空间扩展到四个专家——LRU、LFU、ARC、LFUDA（带动态老化的 LFU）——并用强化学习（爬山法 + 奖励反馈）在专家间切换：

- **状态**：当前各专家的近期命中率统计
- **动作**：选择本驱逐事件由哪个专家决策
- **奖励**：后续命中/缺失反馈（延迟奖励通过折扣处理）
- **在线适应**：无需离线训练，纯在线学习

**实验结论**（对多种真实负载）：相对 LRU 平均命中率提升显著，且在时变负载（阶段性切换局部性模式）下优势最大——验证了"学习价值来自适应性"的核心假设。

**实践意义**：CACHEUS 证明多专家 + 在线学习在系统缓存（磁盘块、CDN）上实用可行，其代码开源（sylab 组织），已成为学习缓存的评测基准之一。

## 6. LRB：基于贝尔曼方程的学习替换

LRB（Learning-based Replacement，Song et al., EuroSys 2020）将驱逐决策形式化为马尔可夫决策过程，用贝尔曼方程指导：

- **状态表示**：每个缓存对象由特征向量描述（访问间隔统计、对象大小、访问频率、最近访问时间）
- **Q 值学习**：学习"在当前状态下驱逐对象 $x$ 的长期代价"的 Q 函数
- **决策**：驱逐 Q 值（长期代价）最大的对象

与 LeCaR 的"专家混合"不同，LRB 直接在对象粒度做价值评估，粒度更细，但需要更复杂的状态管理与探索-利用平衡。

## 7. SHiP与SHiP++：签名命中预测

SHiP（Signature Hit Predictor）系列为每个对象维护访问签名（如触发访问的 PC/指令），统计"该签名对应的对象被重用"的历史频率：

- **学习**：签名 → 重用概率的频次统计（无参数学习）
- **决策**：重用概率低的对象优先驱逐
- **SHiP++**：引入动态老化与多签名融合，MPKI 进一步降低

SHiP 系列说明：即使最简单的统计学习（频次表）也能显著超越纯启发式——学习缓存的门槛可以很低。

## 8. 3L-Cache：低开销精确学习

3L-Cache（Zhou et al., FAST 2025）针对学习缓存的两大实用障碍——训练开销与推理延迟——提出系统级解决方案：

- **轻量模型**：基于逻辑回归 / 小 MLP 的逐对象重用预测
- **低开销管线**：预测仅在驱逐决策点触发（而非每次访问），配合 SIMD 批量推理
- **接近 Hawkeye 精度**：以 1-2% 的额外 CPU 开销换取接近离线训练模型的命中率

3L-Cache 代表了 2025 年的工程共识：**学习缓存的竞争力取决于"每缺失节省的微秒数"与"学习开销的微秒数"之差**。

## 9. KV Cache驱逐的强化学习

大模型推理的 KV Cache 驱逐（详见 [04.03.15 大模型推理缓存架构](../../04-架构设计/04.03-行业应用场景/04.03.15-大模型推理缓存架构.md)）是学习型缓存的最新战场：

- **问题**：GPU 显存有限，超长上下文必须驱逐部分 token 的 KV
- **RL 建模**（Apple ML Research, 2025）：状态 = 当前 KV 集合 + 注意力统计；动作 = 驱逐哪个 token 的 KV；奖励 = 生成质量保持度
- **注意力先验**：H2O（累积注意力分数驱逐）、SnapKV（观察窗口注意力聚类）、StreamingLLM（注意力接收保留）提供无学习基线；RL 方法在其上学习"任务特定的驱逐策略"

**与传统缓存的对应**：token 即对象、注意力分数即"被使用频率"的隐式度量、驱逐即预填充重算成本的规避。学习方法的引入是因为注意力模式是任务相关的（代码补全 vs 长文摘要的最优驱逐不同），单一启发式无法覆盖。

## 10. 学习型与启发式策略的权衡

| 维度 | 启发式（LRU/ARC/S3-FIFO） | 学习型（LeCaR/CACHEUS/3L-Cache） |
| ---- | -------------------------- | --------------------------------- |
| 最坏情况 | 竞争比已知（LRU = $k$） | 依赖鲁棒性设计，可能退化 |
| 平均命中率 | 固定上限 | 可超越最优固定启发式 |
| 决策开销 | O(1)、无模型 | 预测/推理开销（微秒-毫秒级） |
| 内存开销 | 链表/计数器 | 特征、模型权重、历史队列 |
| 适应性 | 无 | 在线适应负载变化 |
| 可解释性 | 高 | 低-中（特征贡献可分析） |
| 工程成熟度 | 极高（内核级实现） | 中等（3L-Cache 等已开源） |

**非学习型的重要补充**（2023-2024 新进展，与本主题对照）：

- **S3-FIFO**（Yang et al., 2023）：三个 FIFO 队列 + 准入控制，简单结构达到接近 ARC 的效果，挑战"学习才能超越经典"的假设
- **SIEVE**（Zhang et al., 2024）：单队列懒惰晋升，代码仅 30 行，在 Web 缓存负载上超越 LRU
- **LHD**（Beckmann et al., 2018）：按"命中密度"（期望命中数/对象大小）驱逐，模型驱动但无在线学习

这些工作提示：在投入学习型方案前，应先确认简单启发式（S3-FIFO/SIEVE/TinyLFU）是否已足够——学习缓存的净收益 = 命中率增益 - 开销成本，在许多场景前者被后者吞没。

## 11. 工程实践指南

**何时引入学习缓存**：

1. 负载时变且异构（多租户、多应用混合）
2. 缺失成本高（如后端是慢存储或昂贵计算）
3. 决策延迟预算充足（微秒级延迟可接受，非 CPU 流水线内部）
4. 有历史访问数据可用于离线评估

**引入路径**：

1. 先建立启发式基线（LRU、ARC、S3-FIFO、TinyLFU）的命中率基准
2. 部署预测级方案（学习"重用概率"，决策仍用经典规则）——风险最低
3. 试点决策级方案（LeCaR 双专家起步），对比净收益
4. 监控：命中率、决策延迟、内存开销、最差情况退化

**反模式**：

- 在 CPU 芯片缓存（纳秒级决策）直接套用毫秒级推理模型
- 无基线对比即宣称学习收益
- 忽略模型失效时的鲁棒性兜底
