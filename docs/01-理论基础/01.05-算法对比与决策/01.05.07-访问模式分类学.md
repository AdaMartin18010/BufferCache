# 01.05.07 访问模式分类学（Access Pattern Taxonomy）

> 访问模式是缓存设计的逻辑结构输入。本文建立七维访问分类学，每维给出**可测量指标 + 缓存设计含义映射**（选什么算法/拓扑/失效链路），与 [05.01.06 全链路 Metric](../../05-全栈分析/05.01-硬件层深度剖析/05.01.06-缓存系统三层结构与全链路Metric.md)、[01.05.04 基准框架](01.05.04-算法性能基准测试.md)、TC-BENCH 工具联动。判定指纹 F23 已入册。

## 1. 七维分类

### D1 读写比（Read/Write Ratio）

| 类 | 度量 | 典型场景 | 设计含义 |
| -- | ---- | -------- | -------- |
| 读密集（>9:1） | GET 占比 | 商品详情/配置/Feed | 命中率是第一指标；驱逐策略选 LRU/LFU 均可，重点在预热与防击穿 |
| 写密集（<2:8） | SET 占比 | 计数器/会话续期/限流 | 写放大主导（AOF/复制）；allkeys-lfu 保热点；TTL 短化 |
| 混合（2:8~9:1） | — | 通用 API | 分层缓存收益最大（读写各自优化层） |

### D2 空间局部性（Sequential/Random）

| 类 | 度量 | 场景 | 设计含义 |
| -- | ---- | ---- | -------- |
| 顺序扫描 | 连续 key 段访问 | 报表/遍历/备份 | **扫描污染**——必须准入过滤（S3-FIFO/W-TinyLFU）或旁路（[01.02.10](../../01-理论基础/01.02-高级替换算法/01.02.10-S3-FIFO与SIEVE算法.md)） |
| 随机热点 | Zipf s≈0.8-1.2 | Web/社交 | LFU 系优于 LRU（TC-BENCH-007 实测依据） |
| 均匀随机 | 平坦分布 | 会话 token | 无热点收益，容量与驱逐简单（随机即可） |

### D3 热点集中度（Skewness）

| 类 | 度量 | 设计含义 |
| -- | ---- | -------- |
| 极热少数（Top 10 承载 >50%） | P99/P50 QPS 比 | 本地缓存一级必配（[04.04.04](../../04-架构设计/04.04-缓存问题与治理/04.04.04-热点Key问题.md)） |
| 中度倾斜 | Zipf 中段 | 单飞+TTL 抖动即可 |
| 访问簇（key 关联） | 条件共现率 | 泊松热点假设失效（[01.03.05](../../01-理论基础/01.03-分布式缓存算法/01.03.05-数据分片数学与再平衡模型.md) §4）——按簇建模 |

### D4 时间局部性（重用间隔）

| 类 | 重用间隔 | 设计含义 |
| -- | -------- | -------- |
| 短重用（秒-分） | — | 大容量收益低（ churn 快），小容量+激进驱逐 |
| 长重用（小时-天） | — | 大容量+低频驱逐；TTL 是主失效 |
| 一次性 | 永不重用 | **不应缓存**（布隆拦截或直写 DB）；缓存负收益 |

### D5 交互形态（Interaction Shape）

| 类 | 场景 | 设计含义 |
| -- | ---- | -------- |
| 请求-响应 | REST/RPC | 标准缓存模式（Cache-Aside） |
| 流式（SSE/WebSocket） | 实时推送 | 缓存热点快照+增量（[04.04.08 §4 级联](../../04-架构设计/04.04-缓存问题与治理/04.04.08-缓存失效传播与一致性链路.md)）；连接态不缓存 |
| 批式 | ETL/预计算 | 旁路缓存（批后回填），防扫描污染 |

### D6 值大小分布（Value Size）

| 类 | 大小 | 设计含义 |
| -- | ---- | -------- |
| 小（<1KB） | — | listpack 编码红利（[03.01.13](../../03-Redis组件/03.01-核心数据结构/03.01.13-序列化编码与内存布局权衡.md)）；序列化选 JSON/MP |
| 中（1KB-64KB） | — | 标准；注意网络帧效率 |
| 大（>64KB） | — | 拆分/压缩/UNLINK 删除；bigkey 三板斧（[07.07.03](../../07-运维与部署/07.07-自动化运维/07.07.03-性能诊断与火焰图实践.md)） |

### D7 TTL 形态（Expiration Shape）

| 类 | 场景 | 设计含义 |
| -- | ---- | -------- |
| 无 TTL（手动管理） | 参考数据 | 失效链路选 CDC/主动删除 |
| 固定 TTL | 会话 | 抖动防雪崩（[04.04.02](../../04-架构设计/04.04-缓存问题与治理/04.04.02-缓存雪崩.md)） |
| 分层 TTL（长短混合） | 多级缓存 | L1 短（分钟）/L2 长（小时）——级联失效窗口设计（04.04.08 §4） |

## 2. 组合指纹（常见复合模式）

| 指纹 | 组合 | 推荐架构 |
| ---- | ---- | -------- |
| F23-a | 读密集+随机热点+短重用+小值 | 应用内 Caffeine（LFU）+ 短 TTL |
| F23-b | 读密集+顺序扫描混合 | W-TinyLFU 准入 或 S3-FIFO（扫描抗性实测依据 01.05.04） |
| F23-c | 写密集+小值+固定 TTL | allkeys-lfu + AOF everysec + TTL 抖动 |
| F23-d | 流式+热点集中 | 本地快照缓存 + 增量广播失效 |
| F23-e | 批式+顺序 | 旁路（不缓存批路径）+ 批后回填 |
