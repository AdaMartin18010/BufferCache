## 1. 四维决策矩阵

| 策略 | RPO 目标 | 性能代价 | 成本 | 运维复杂度 |
| ---- | -------- | -------- | ---- | ---------- |
| 无持久化 | 全丢（缓存语义） | 无 fork/IO | 磁盘零 | 最低 |
| RDB only | ≤ 快照间隔 | fork 峰值 + 突发写 | 磁盘 = 数据快照 | 低 |
| AOF everysec | ≤ 1s | fsync 每秒 + AOF 重写 | 磁盘 ≈ 2-3× 数据（重写前） | 中 |
| AOF always | ≈ 0 | 每请求 fsync（吞吐 -30%+，C 级） | 同上 | 中 |
| 混合持久化 | ≤ 1s（everysec） | fork + fsync 组合 | 磁盘 ≈ 2× 数据 | 中高 |

## 2. 成本公式

### 2.1 磁盘 IOPS 账（推导自写入路径，B 级）

AOF everysec 的稳态磁盘写：

$$IOPS_{aof} = \frac{W_{rate}}{B_{batch}} + 1 \approx 1\text{-}10 \quad (W: 写入字节/秒, B_{batch}: fsync 合并批量)$$

RDB 快照的突发磁盘写（快照间隔 $T_r$）：

$$IO_{burst}^{rdb} = \frac{D}{T_r} \quad (D: 数据全集)$$

**判据**：磁盘是云盘时突发写受 IOPS/带宽双限（阿里云 ESSD 级联规则），快照间隔 $T_r \geq D / B_{disk}^{sustained}$，否则快照窗口内 IO 饱和影响主流程（C 级云工程经验）。

### 2.2 fork COW 内存账（官方文档 + 工程经验，B/C 级）

$$M_{cow} = W_{during\_fork} \times t_{fork} \times 2$$

写密集期 fork 的 COW 内存可达数据集 20-40%（Redis 官方持久化文档给出 2 倍写放大口径，C 级经验 20-40% 为生产实测区间）。**maxmemory 配置必须预留 COW 余量**（安全水位 70% 的隐含理由，[07.05.04](../../07-运维与部署/07.05-集群管理/07.05.04-集群容量规划.md) 联动）。

### 2.3 恢复时间账（TC-CLUS-006 实测联动）

| 路径 | 恢复耗时构成 | 实测锚点（2026-11-17） |
| ---- | ------------ | --------------------- |
| RDB | 启动 + RDB 加载（线性于数据量） | 5 keys 瞬时；大实例分钟级 |
| AOF | 重放日志（线性于日志量） | 同上 |
| 混合 | RDB 前缀 + AOF 尾部重放 | 最优 |

## 3. 持久化与驱逐/复制的交互

| 交互 | 行为 | 风险 |
| ---- | ---- | ---- |
| fork 期间 maxmemory 驱逐 | 正常进行（逐出线程不受 fork 阻塞），但 fork 子进程共享内存 → **实际可用内存收紧** | OOM 误判风险上升 |
| bgsave 与 AOF 重写并发 | Redis 串行化后台任务（同一时刻一个子进程） | 第二个任务排队，延迟尖峰 |
| 复制全量同步 + 持久化 | diskless 复制（7.x+）RDB 直发网络 | 无盘复制期间 fork COW 峰值 |
| AOF 磁盘满 | 默认拒绝写（no-appendfsync-on-rewrite 无关） | 雪崩式写失败，需磁盘水位告警 |

## 4. 决策流程

```text
数据可重建（纯缓存/可回源）？
├─ 是 → 无持久化 或 RDB 低频兜底（小时级快照，灾备用）
└─ 否 → RPO ≤ 1s 可接受？
    ├─ 是 → AOF everysec + 混合持久化（生产默认）
    └─ 否 → AOF always（吞吐换零丢失）或 主从+哨兵补偿（不写 always 靠副本）
          └─ 资金类 → 改用 RedLock 共识或 DB 直写（缓存不承担持久性）
```

## 5. 场景速查

| 业务 | 推荐 | 关键参数 |
| ---- | ---- | -------- |
| 会话缓存 | 无持久化 / RDB 兜底 | save 900 1 |
| 购物车/订单快照 | AOF everysec + 混合 | auto-aof-rewrite-percentage 100 |
| 计数器/限流 | AOF everysec | appendfsync everysec |
| 消息队列（Stream） | AOF everysec + 从副本 | maxmemory-policy noeviction |
| 分布式锁 | AOF always（锁语义依赖）或 共识锁 | 见 [08.03.01](../../08-分布式架构/08.03-分布式协调/08.03.01-分布式锁实践.md) |
