# 04.03.21 语义缓存与 Agentic 应用缓存

> 04.03.15-18 覆盖推理层 KV 缓存；本文补齐**应用层**缓存谱系：语义缓存（embedding 相似复用 LLM 响应）与 2026 年最热点的 **Agentic 工作流缓存**。判定指纹 F25 已入册。

## 1. 应用层 LLM 缓存三层

```text
L1 Provider Prompt Cache（供应商侧，前缀级）
   供应商缓存已见前缀的 KV，命中部分计费 50-90% 折扣；零应用改动，但受供应商窗口限制
L2 语义缓存（应用侧，响应级）
   embedding 相似度检索复用完整响应；本文主体
L3 KV/前缀缓存（推理引擎侧，token 级）
   [04.03.15](../04.03-行业应用场景/04.03.15-大模型推理缓存架构.md) 主体
```

三层正交可叠加：L1 省 prefill 算力、L2 省完整推理调用、L3 在 L1/L2 miss 后省重复 prefill。

## 2. 语义缓存机制与谱系

**机制**：prompt → embedding → 向量库近邻检索（cosine ≥ θ）→ 命中则返回缓存响应（3-8ms vs 完整推理 500-2000ms）；miss 则调 LLM 并写入缓存。谱系（[NomadX 2026-08](https://nomadx.ae/blog/semantic-caching-llm-chatbots-gptcache-portkey-redis-2026/)；[spheron 2026-04](https://www.spheron.network/blog/semantic-cache-llm-inference-gpu-cloud/)，C 级交叉核验）：

| 系统 | 年代 | 贡献 |
| ---- | ---- | ---- |
| GPTCache（Zilliz, [NLP-OSS/ACL 2023](https://aclanthology.org/anthology-files/pdf/nlposs/2023.nlposs-1.24.pdf)） | 2023 | 开创 embedding 相似度缓存；Onnx 轻量向量（无 API key）+ SQLite/Faiss 后端 |
| RAGCache（Jin et al. 2024） | 2024 | 扩展到检索增强生成的缓存 |
| vCache（2025） | 2025 | **验证式**语义缓存 + 自适应相似阈值 |
| InstCache/GenCache | 2025 | 领域化变体 |
| 企业网关内建（Portkey 等） | 2025-2026 | 网关层语义缓存 + 成本追踪 |

**关键指标**（2026 实测汇总，C 级）：真实聊天流量命中 25-35%；agent/FAQ 负载 30-70%；**阈值起点 FAQ bot 0.90-0.93 cosine**（低于此错误命中显著上升）；开销 2-10ms/次（GPTCache 3-10ms / Redis Vector 2-5ms）。

## 3. 精度-召回权衡与错误命中

语义缓存的本质是**精度-召回权衡**（[arXiv 2602.18922](https://arxiv.org/html/2602.18922v1)，2026-02）：阈值低→命中率高但错误命中（语义相近但正确答案不同的查询被复用）→**比 miss 更糟**（返回错误答案）。治理：

| 手段 | 机制 |
| ---- | ---- |
| 阈值分域 | FAQ 0.90-0.93 起步；高风险域（医疗/法律）提高到 0.97+ 或禁用语义缓存 |
| 验证式缓存（vCache 思路） | 命中后小模型/规则二次验证再返回 |
| 时效隔离 | 时间敏感答案（价格/新闻）不缓存或秒级 TTL |
| 个性化隔离 | key 维度加入用户/租户标识（[How LLM Wiki](https://llmwiki.hu/concepts/semantic-caching)） |

**安全面**：NDSS 2026《Cache Me, Catch You》（[GitHub](https://github.com/XingTuLab/Cache_Me_Catch_You)）披露 vLLM/SGLang/GPTCache 的**前缀哈希碰撞攻击**——攻击者构造哈希同前缀的请求窃取他人缓存内容；以及敏感响应的语义邻域探测。防护：缓存键加盐、租户隔离、命中审计（与 04.02 缓存安全联动）。

## 4. Agentic 工作流缓存（2026 前沿）

Agent 多步推理带来新缓存对象（[arXiv 2602.18922](https://arxiv.org/html/2602.18922v1)）：

| 缓存对象 | 复用粒度 | 状态 |
| -------- | -------- | ---- |
| 工具调用结果 | 函数+参数规范化后精确/模糊匹配 | 成熟（副作用工具除外） |
| Agent 计划（Plan Caching, APC） | 意图规范化后的计划复用 | 研究前沿（意图规范化是关键难点——"帮我订机票"的 20 种说法需归一到同一计划键） |
| 中间推理态 | 子目标结果 | 探索期 |

**反模式**：直接缓存原始 prompt 的 embedding（不做意图规范化）——paraphrase 精度损失使命中失真；Few-Shot 意图规范化是当前有效路径。

## 5. 判定指纹（F25）

| 指纹 | 结论 | 锚点 |
| ---- | ---- | ---- |
| F25-a | 高重复问答+非时效+非个性化 → L2 语义缓存 | §2 阈值 0.90-0.93 起步 |
| F25-b | 供应商已提供前缀缓存 → L1 优先（免费午餐） | §1 |
| F25-c | 高风险域（医疗/法律/金融建议） → 语义缓存禁用或验证式 | §3 |
| F25-d | 副作用工具调用 → 不缓存 | §4 |
| F25-e | Agent 计划复用 → 先意图规范化再缓存 | §4 |
