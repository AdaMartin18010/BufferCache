# 04.05.06 缓存能效与可持续性

> 能效是 2024-2026 国际大主题（IEA 数据中心电力报告、Green Software Foundation），项目此前只算钱不算电。本文建立缓存的能耗视角：量化模型、国际指标、设计含义。

## 1. 为什么缓存是能效杠杆

缓存命中的本质是把"全链路重算"（CPU+网络+存储的完整能耗）换成"一次内存读"（纳焦级）。一次 Web 请求的能耗分解中，**数据访问路径（DB 查询+序列化+网络往返）常占大头**——命中缓存可削减该路径能耗的 90%+（与 05.01.06 链路账同构：省的是左侧高能耗层级）。

## 2. GSF 软件碳强度指标（SCI）

Green Software Foundation 的 SCI 公式（A 级标准）：

$$SCI = rac{E  imes I  imes M}{R}$$

- E = 软件能耗（kWh）、I = 电网碳强度（gCO₂/kWh，区位相关）、M = 硬件隐含碳摊销、R = 功能单位（如每千次请求）
- **缓存的设计含义**：提高命中率直接降低 E/R（每请求能耗）；选用低碳区位的缓存节点（I）与延长硬件寿命（M，内存超售率）同样入公式。

## 3. 缓存能效的四个设计杠杆

| 杠杆 | 机制 | 量化方向 |
| ---- | ---- | -------- |
| 命中率 | 省全链路重算 | 命中率每 +10pp ≈ 每请求能耗 -X%（ workload 相关，项目压测校准） |
| 分层介质 | 热数据 DRAM/温数据 CXL（[05.01.6 §2.1](../../05-全栈分析/05.01-硬件层深度剖析/05.01.06-缓存系统三层结构与全链路Metric.md)：CXL 400-700ns 但**内存密度 2-4×、每 GB 能耗更低**） | 每 GB 能耗：DRAM > CXL > SSD |
| 压缩与编码 | listpack/序列化（[03.01.13](../../03-Redis组件/03.01-核心数据结构/03.01.13-序列化编码与内存布局权衡.md)）降内存占用→同容量更少 DIMM | 内存条数 ∝ 隐含碳与待机功耗 |
| 空闲降频 | 缓存集群潮汐（[05.03.6 §5](../../05-全栈分析/05.03-控制流分析/05.03.06-缓存交互动态设计.md)）低谷缩容 | 直接降 E |

## 4. 测量与披露

- **工具**：GSF 的 SCI 计算器/CO2.js（网格碳强度 API）；云厂商碳足迹工具（AWS Customer Carbon Footprint）按服务拆分。
- **披露趋势**：欧盟 CSRD/ESRS 要求大企业披露 IT 能耗；Green Software 正成为 RFP 评分项（C 级趋势判断，随季度核验）。
- **项目行动**：bench_suite 增补能耗维度（RAPL 功耗计数 `--energy` 档）；验收报告加"每千请求能耗"列。
