# 05.01.06 缓存系统三层结构与全链路 Metric

> 本文建立缓存系统的**结构主义框架**：物理结构（硬件全链路 metric 权威表）/ 形式结构（部署拓扑形态学）/ 逻辑结构（数据流·控制流·访问模式），并定义三层间的映射规则。本文是项目全部硬件数据的**权威源**——[02.02](../../02-系统实现/02.02-CPU缓存架构/)、[05.01 其他篇](./)、[05.02](../05.02-网络通信层/) 的数值均投影自本文。

## 1. 三层结构框架

```text
物理结构（Physical）—— 存取介质与互连：寄存器→L1/L2/L3→DRAM→NVMe→CXL→网络
   ↑ 决定                ↓ 提供
形式结构（Formal）—— 部署拓扑：单机/主从/Cluster/分层/边缘，组件的连接形态与数据放置
   ↑ 决定                ↓ 提供
逻辑结构（Logical）—— 访问语义：数据流（读路径/写路径）、控制流（调度/失效）、访问模式（分类学见 01.05.07）
```

**映射规则**：逻辑结构的需求（如"写后读强一致"）→ 形式结构选型（主读/副本拓扑）→ 物理结构约束（副本同步的网络延迟下限）；反过来物理结构的能力（CXL 内存延迟 400-700ns）决定形式结构可行的分层粒度。**三层任何设计决策必须能沿此链双向追溯**——这是与全局一致性规范 §3 决策指纹并列的"结构指纹"。

### 2.1b GPU HBM 与统一内存层级（2026-11-18 扩充）

| 级 | 存取时间 | 带宽 | 一致性域 | 机制 | 出处 |
| -- | -------- | ---- | -------- | ---- | ---- |
| GPU HBM（本地） | ~200-400ns（GPU 视角） | 2-8 TB/s | GPU 设备 | HBM2e/3 堆叠 | 厂商（B） |
| **Grace-Hopper NVLink-C2C 统一内存** | CPU 访问 GPU 显存 ~微秒级（硬件页迁移） | 900 GB/s 双向 | **硬件管理一致性** | 页迁移引擎按访问热度自动迁移 | NVIDIA 文档（B） |
| GPUDirect Storage | GPU 直读 NVMe（绕过 CPU） | NVMe 带宽级 | GPU+存储 | DMA 直通 | [02.03.8 §4](../../02-系统实现/02.03-数据库缓存/02.03.08-数据访问中心设计与PG18解剖.md) |

**缓存层级含义**：统一内存使"HBM 成为 CPU 缓存体系的可迁移层"——LLM KV 分层（[04.03.15 §8](../../04-架构设计/04.03-行业应用场景/04.03.15-大模型推理缓存架构.md)）的 GPU HBM↔CPU DRAM 层在此硬件上由硬件页迁移自动执行（准入判据的硬件化）；代价是页迁移的 μs 级不确定性与命中率不可观测（需厂商工具）。

### 2.2 数量级记忆锚（C 级教学模型）

$$\underbrace{1\text{ns}}_{\text{寄存器}} \to \underbrace{10\text{ns}}_{\text{L3/TLB}} \to \underbrace{100\text{ns}}_{\text{DRAM}} \to \underbrace{1\mu\text{s}}_{\text{CXL}} \to \underbrace{10\mu\text{s}}_{\text{NVMe}} \to \underbrace{100\mu\text{s}}_{\text{同 AZ}} \to \underbrace{1\text{ms}}_{\text{跨 AZ}} \to \underbrace{10\text{ms}}_{\text{全球}}$$

每跨一级代价 ×10——缓存层级设计的本质是把访问尽量挡在左侧。

### 2.3 并发与一致性维度的结构性约束

| 约束 | 内容 | 设计含义 |
| ---- | ---- | -------- |
| 一致性域边界 | 核内（寄存器）→核间（MESI）→插座（NUMA）→机架（CXL）→机房（网络）——每跨域一致性成本跳变 | 缓存数据放置尽量在一致性域内（NUMA 本地 L3 vs 跨插座内存） |
| 并发度饱和点 | 单核内存级并行 MLP~10-20；DRAM 通道数决定总并发；网络受拥塞控制 | 异步/批量（pipeline）是把并发度喂满的手段（io_uring 意义所在） |
| PCIe 6.0/CXL 3.0 拐点 | 2026 合规验证阶段；PCIe 6.0 带来 2× 带宽与更优 CXL IP（ReScue, HPCA 2026） | 分层内存从"实验"走向"量产"，内存池化架构窗口开启 |

## 3. 形式结构：部署拓扑形态学

| 拓扑 | 连接形态 | 数据放置 | 扩展单元 | 一致性机制 | 指纹 |
| ---- | -------- | -------- | -------- | ---------- | ---- |
| 单机 | 进程内/loopback | 单机内存 | 垂直（升配） | 无（单写者） | F19-a |
| 主从 | 星形（主→从复制） | 主全量+从副本 | 读副本 | 异步复制+滞后预算 | F7 |
| Cluster 分片 | 全互联 Gossip | 槽位分片 | 水平分片（reshard） | 槽位仲裁+epoch | F17 |
| 分层（多级） | 树形（CDN→本地→远程→DB） | 热度分层 | 各层独立 | TTL/失效传播 | §4.44.08 |
| 边缘网格 | PoP 星形+全球清除 | 地理分布 | PoP 数量 | TTL+全球清除 | F20 |
| 数据网格 | 对等网格（分片+计算） | 计算与数据同址 | 网格节点 | 可配事务 | F22-f |
