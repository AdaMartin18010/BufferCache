# 05.03.06 缓存交互动态设计

> 应用与缓存的**交互语义层**：同步/异步、会话亲和、连接动态、并发模型——这些"形式结构之下的交互结构"决定缓存的真实时延与吞吐形态。与 [05.03 控制流](./)（引擎内部）互补：本文管**应用侧**交互设计。

## 1. 同步语义三档

| 档位 | 语义 | 缓存交互 | 适用 |
| ---- | ---- | -------- | ---- |
| 同步 | 调用方阻塞等结果 | 标准 GET/SET；超时即失败 | 强依赖数据的读路径 |
| 异步（fire-and-forget） | 不等待结果 | 缓存写（回填/失效）异步化；读不适用 | 写后失效、计数上报 |
| 半同步（future/回调） | 并发发多个读，汇合点等待 | 缓存+DB 双读竞速（cache-aside 并发版）；扇出聚合 | 高扇出读（Tail at Scale 缓解） |

**判定**：写路径异步化是免费午餐（无调用方等待）；读路径异步化只在扇出 ≥3 时收益（并发等待省串行 RTT）。异步的失效传播必须配对幂等消费（[04.44.08 §2.2](../../04-架构设计/04.04-缓存问题与治理/04.04.08-缓存失效传播与一致性链路.md)）。

## 2. 会话亲和（Session Affinity）

| 模式 | 机制 | 缓存含义 | 指纹 |
| ---- | ---- | -------- | ---- |
| 无状态 | 任意实例服务 | 会话必须外置缓存（Redis/PG） | 默认 |
| 粘性会话 | LB 按用户路由 | 会话可本地缓存（但实例故障=会话丢失） | [07.04.04 会话级多活](../../07-运维与部署/07.04-故障处理/07.04.04-跨机房多活缓存设计.md) |
| 亲和+外置 | 本地缓存+外置兜底 | 读本地 miss→外置→回填本地；写穿透外置 | 高性能会话 |

**反例**：粘性会话+本地缓存+无 TTL = 实例内存泄漏与一致性地雷；粘性必须配 TTL 与故障转移重建路径。

## 3. 连接动态（Connection Dynamics）

| 项 | 设计 | 依据 |
| -- | ---- | ---- |
| 连接池 | 有界池（max_connections）+ 池等待上限 | [03.06.07 矩阵](../../03-Redis组件/03.06-网络通信/03.06.07-客户端连接与重试行为矩阵.md)：无界池=故障时线程池击穿 |
| 连接复用 | 长连接+健康检查（health_check_interval） | 连接重建的 TCP+AUTH 成本 ~ms 级 |
| 突发吸收 | 池满策略：快速失败优于无限排队 | 排队等待时间进入延迟账（05.06.07 边界模型计入 W） |
| 背压传导 | 池满→上层熔断（[02.06.01](../../02-系统实现/02.06-程序设计实践/02.06.01-容错机制设计.md)） | 缓存故障不拖垮应用线程 |

## 4. 并发模型 × 缓存访问路径

| 应用并发模型 | 缓存访问形态 | 注意 |
| ------------ | ------------ | ---- |
| 线程/连接池（Tomcat 类） | 每线程一个池化连接 | 线程数×连接数配比（03.06.7 §4） |
| 事件循环（Node/Netty） | 单连接多路复用 | 缓存客户端必须异步非阻塞（redis-py asyncio 版）；阻塞客户端=事件循环灾难 |
| 协程（Go/asyncio） | 协程共享池连接 | 协程数 >> 连接数时池等待是主要延迟源 |
| 批量/流水线 | MGET/Lua 合并 | 把并发度喂满物理结构（05.01.6 §2.3 MLP）；pipeline 深度 10 是基准常见点（Valkey 9.1 官方基准口径） |

## 5. 互联网访问设计（突发/潮汐/全球）

| 形态 | 特征 | 缓存应对 |
| ---- | ---- | -------- |
| 突发（秒杀/热搜） | 秒级 10-100× 基线 | 预热（[04.44.09](../../04-架构设计/04.04-缓存问题与治理/04.04.09-缓存预热与冷启动治理.md)）+ 单飞 + 限流；指纹 F23-a/b |
| 潮汐（日/周周期） | 可预测 3-10× | 主动伸缩（[07.09.04 §2](../../07-运维与部署/07.09-弹性伸缩与自愈/07.09.04-分片级弹性伸缩与分区迁移.md) 超限暴露量模型） |
| 全球分布 | 跨洲 RTT 100-300ms | CDN 边缘（[04.03.20](../../04-架构设计/04.03-行业应用场景/04.03.20-CDN与边缘缓存架构.md)）+ 区域化缓存副本 |
| 爬虫/机器流量 | 扫库式访问 | 布隆过滤 + 速率限制；勿让其污染热点统计（D2 扫描污染同源） |
