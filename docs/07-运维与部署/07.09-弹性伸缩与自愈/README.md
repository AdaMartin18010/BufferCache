## 快速决策

```text
副本数随负载变？        → HPA（CPU/内存）或 KEDA（队列/事件，可缩到 0）
单 Pod 规格不合理？     → VPA（推荐模式先行，不与 HPA 同指标并用）
节点不够用/浪费？       → Karpenter（AWS，快+省）或 Cluster Autoscaler（通用）
缓存容量告警？          → 内存水位外部指标 → HPA + Cluster 分片扩容双轨
进程/Pod 挂了？         → 重启策略 + 探针（K8s 自动）
实例挂了？              → Sentinel/Cluster 自动转移（见 07.05）
整机房挂了？            → 多活 + DNS/Anycast 切换（预案驱动，07.04）
```
